Core Management Functions

add_box Add a record

Creates a new entry. A form will pop up and kindly fill in the details then submit.

e.g. adding a new employer

edit_note Edit a record

Updates an existing entry's information without creating a duplicate.

e.g. correcting a wrong amount

delete_forever Delete a record

Permanently removes an entry. You'll be asked to confirm before it's deleted.

e.g. removing a duplicate row

search Search & filter

Type anything in the search bar to narrow down the list instantly.

e.g. searching by member ID or name

What the Colored Banners Mean

check_circle

Green — done

Your action was saved successfully. No further steps needed.

e.g. "Record added successfully into the relation!"

warning

Yellow — please confirm

You're about to make a change that can't be undone. Read the prompt carefully before clicking yes.

e.g. "Are you sure you want to delete this record?"

error

Red — something went wrong

The action didn't go through. Check if any required fields are empty or if you're still connected to the network.

e.g. "Validation Blocked: Missing mandatory fields."
